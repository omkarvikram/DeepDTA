Read the scores correctly

MSE: average squared difference between predictions and benchmark values. Lower is better. RMSE: square root of MSE, expressed in the model’s score units. CI: how often the model orders two unequal measured affinities correctly; 1 is perfect ordering, 0.5 is the constant-prediction baseline. A tied prediction contributes one half; tied measured labels are excluded.

CI is a ranking metric. CI = 0.86 does not mean each numerical affinity is “86% accurate.” The best MSE model need not have the best CI. This study selects on validation MSE and reports both metrics without changing the winner after seeing test results.

What needed correction

The supplied Davis notebook fits only the first training fold and uses the supplied test fold as validation during training. The supplied KIBA notebook’s saved history shows validation error increasing sharply while training error keeps declining. Both issues make blindly increasing epochs unreliable.

This study uses training folds 2–5 for fitting, fold 1 for model selection, and the supplied test fold only after candidate selection. It removes overlapping input pairs, fits token vocabularies and target scaling on training data, and saves the best validation checkpoint.

How the experiment works

The initial search plan was narrowed before test evaluation after measuring CPU cost and validation results. Davis retained all seven CNN screen arms; KIBA retained the three learning-rate arms. Longer CNN runs were restricted to Davis’s baseline and best screening configuration. Both datasets retained the three sequence-feature trials and a second-seed repeat of the best overall configuration. The original and amended protocols are included for transparency; unrun configurations are not claimed as tested.

  1. Read the supplied data safely. Read the two ZIP files’ JSON and text tables. Do not run uploaded notebooks or deserialize their pickle files. Record SHA-256 checksums.
  2. Build paired inputs. Map each finite matrix entry to its compound and protein sequence. Retain only the supplied pairs and their original fold assignments. Convert Davis Kd nM to pKd; leave KIBA labels on their own scale.
  3. Clean split overlap. Remove training pairs also represented in validation/test and validation pairs represented in test. Include collisions caused by legacy truncation. Use this same conservative split for every trial.
  4. Encode without fitting on validation labels. CNNs use integer SMILES tokens and amino acids, with separate padding and unknown codes. Embeddings have 32 dimensions. The existing n-gram control uses deterministic 2,048-dimensional features per input.
  5. Test capacity and learning rate. CNN filters: 8/16/24, 16/32/48 or 32/64/96. Drug kernel width 4; protein width 8. Global max pooling replaces the large flattening representation in the supplied KIBA notebook. The two pooled vectors pass through 256/128 dense layers. Initial Adam learning rates: 0.0003, 0.001 and 0.003. CNN batches contain 1,024 pairs; sequence-feature batches contain 256. Cross-family comparisons therefore include different update budgets and must not be interpreted as an isolated architecture effect.
  6. Regularize and scale. CNN head dropout 0.2, L2 penalty 0.00001 and gradient clipping 1. Predict a standardized training target internally and rescale to pKd/KIBA at the output. Report raw MSE without the regularization penalty.
  7. Reduce the learning rate and stop. Halve LR after four epochs without a validation-MSE improvement of at least 0.00001, down to 0.00001. Stop after 12 such epochs and restore the best checkpoint. A fixed-LR comparison disables the LR reductions.
  8. Use computation efficiently. Calculate each unique drug/protein encoder once within a batch, then gather its representation for the corresponding pairs. Pair-head dropout still uses a separate mask for each pair. A gradient-equivalence test checks this against ordinary repeated-input computation.
  9. Repeat and freeze. Repeat the best overall configuration per dataset using seed 123, compare its fixed two-seed mean using validation only, also compare one fixed 50:50 blend of the best CNN and best sequence-feature candidate on validation, then freeze model hashes and selection before test evaluation.
  10. Report limits. Keep train/validation curves, all trial scores, best/stopping epochs, test predictions and configuration files. No independent clinical or cold-input accuracy is inferred.

The existing n-gram baseline uses branch sizes 128/64 and head 128/64 with dropout 0.1 after the first head layer. Its wider variant uses 256/128 branches and head, dropout 0.2 and L2 0.00001. These are already within the project’s technology stack; no graph network, transformer, pretrained language model or new training framework was introduced.

What would improve confidence further?

  1. Use a genuinely separate experimental benchmark. Obtain exact compound/protein Kd records from ChEMBL, retain assay/document identifiers, match the protein construct and organism, normalize concentration units, and remove overlap with all training/selection data. Keep this benchmark outside hyperparameter selection.
  2. Expand training only after curation. ChEMBL can supply additional Kd data for a pKd model. Separate Kd, Ki, IC50 and functional assay endpoints. KIBA is a combined score, so simply appending ChEMBL pChEMBL or IC50 labels to KIBA training would change the prediction target. No external data were silently added in this study.
  3. Test unseen chemistry and targets. Add compound/scaffold-grouped, protein-sequence-clustered and publication-date splits. Pair-level success can coexist with poor predictions for a new compound family or protein family. Use nested or reserved validation for future architecture searches.
  4. Handle assay uncertainty. Audit duplicates, conflicting replicates, salts, stereochemistry, protein variants and thresholded measurements. Values reported as “greater than” or “less than” are bounds, not exact measurements. A changed loss for censored labels needs a separate controlled experiment.
  5. Calibrate prediction intervals separately. After freezing a model, reserve independent calibration data and assess interval coverage by chemical/protein similarity groups. A model change invalidates previous calibration. Do not invent a per-input accuracy percentage from aggregate MSE or CI.

These are next experiments, not demonstrated gains. A larger dataset can worsen performance if its labels or assay conditions are incompatible.

Files and reproduction

Open Davis_Improved.ipynb or KIBA_Improved.ipynb in the packaged notebooks folder. They explain the data, architecture, comparison procedure and how to use the saved research model. The original uploaded notebooks remain unchanged.

From the package root, with the project’s Python environment activated:

python -m unittest discover -s scripts/model_tuning_tests -v
python scripts/predict_tuned_affinity.py --dataset davis --smiles "CCO" --protein-file protein.txt

The sample command shows syntax only; it does not imply ethanol is a suitable compound for a kinase prediction. Use the supplied example_inputs.json for actual benchmark input pairs. The notebooks provide the exact paired examples and prediction calls.

Use a fresh research output directory for a new experiment. Preserve the completed study: reusing its test results to tune again invalidates the test separation. Initial CNN screens used three intra-operation CPU threads; the Davis full-sequence/fixed-LR arms, KIBA higher-LR arm and later stages used two after the resource amendment. Seeded calculations can differ slightly with thread settings; the fixed-LR and KIBA higher-LR arms are exploratory rather than isolated causal-effect estimates. The Davis CNN learning-rate arms and all n-gram learning-rate arms use matched thread settings. These runs used TensorFlow on CPU; GPU execution was not tested. Wall-clock speed and floating-point results can differ across hardware or library versions. Runs shared CPU resources, so their elapsed times are not a controlled hardware speed benchmark.

Deployment status: these are separate research artifacts. The live website and its existing calibration were not overwritten. Promoting a candidate requires connecting its exact preprocessing, checking predictions, refreshing model metadata and recalibrating any numerical-accuracy intervals. The inference helper supplied here loads the selected candidate with its matching preprocessing. Add --family cnn to choose the best CNN specifically; both families’ trained checkpoints are retained.
